ИНСТРУКЦИЯ: ЛОКАЛЬНЫЙ ЗАПУСК ПРОЕКТА


ЧТО НУЖНО

Node.js (версия 18 или выше).


ШАГ 1. ОТКРЫТЬ ТЕРМИНАЛ В ПАПКЕ ПРОЕКТА

В терминале перейди в папку с проектом.


ШАГ 2. УСТАНОВИТЬ ЗАВИСИМОСТИ

    npm install


ШАГ 3. ПРОВЕРИТЬ СТРУКТУРУ

    src/
    ├── App.jsx
    ├── App.css
    ├── api.js
    └── index.js

И в public/ — файл sp.png (фон чата).


ШАГ 4. ЗАПУСТИТЬ ПРИЛОЖЕНИЕ

    npm start

Если браузер не открылся сам — откройте http://localhost:3000 вручную.


ШАГ 5. ВОЙТИ В ПРИЛОЖЕНИЕ

На экране авторизации введи:

    idInstance        — число из Green API (например, 1101000001)
    apiTokenInstance  — длинная строка-токен (не URL!) из Green API

Нажмите «Войти».

Важно: инстанс должен быть Authorized (зелёный статус).


ШАГ 6. ПРОВЕРИТЬ РАБОТУ

1. Добавь чат: введи номер телефона получателя в поле под «Чаты», нажми «+».
2. Отправь сообщение: напиши текст, Enter.
3. Проверь получателя: на его телефоне должно прийти сообщение.
4. Ответь с телефона: через 5 секунд ответ появится в приложении.


КАК ОСТАНОВИТЬ СЕРВЕР

В терминале, где работает npm start, нажми Ctrl + C.


КАК ЗАПУСТИТЬ СНОВА

    cd путь/к/папке/проекта
    npm start
