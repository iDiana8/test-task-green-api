# План разработки чата с Green API
Порядок действий - логика:

Авторизация: реализовать форму с двумя полями - вводим свою уч.з. от GREEN API

Создание чата: окно -- поле ввода номера -- добавление в список чатов -- боковая панель отображения -- пустая/диалог с др. пользователем 

Далее fetch() → HTTP-запросы к Green API                         │

Отправка сообщения: POST на sendMessage.
Получение сообщений: polling через setInterval каждые 5 секунд.
Подтверждение получения: DELETE на deleteNotification.

Чтобы при перезагрузке страницы чаты не пропадали - сохранение чатов в localStorage.

## Общая логика

| Этап | Что делаем | Метод / механизм |
|---|---|---|
| Авторизация | Форма с двумя полями (учётные данные Green API) | `idInstance`, `apiTokenInstance` |
| Создание чата | Поле ввода номера → добавление в список → боковая панель | `phoneToChatId()` |
| Отправка сообщения | POST-запрос к Green API | `POST sendMessage` |
| Получение сообщений | Периодический опрос сервера | `GET receiveNotification` каждые 5 сек |
| Подтверждение получения | DELETE-запрос после обработки | `DELETE deleteNotification` |
| Сохранение | Не терять чаты при перезагрузке | `localStorage` |

## Подробный порядок действий

### 1. Продумать интерфейс (до кода)

Прежде чем писать JSX, определить:

- **Сколько экранов?** Два: экран авторизации и основной экран чата.
- **Что на экране авторизации?** Форма с двумя полями (`idInstance`, `apiTokenInstance`) и кнопкой «Войти».
- **Что на основном экране?** Три зоны:
  1. Узкая левая полоса с иконками (декоративная).
  2. Панель со списком чатов.
  3. Окно активного чата.
- **Что показывать, если чат не выбран?** Заглушку «Выберите чат».
- **Какие состояния хранить?**
  - `idInstance`, `apiTokenInstance`
  - `isAuthorized`
  - `chats`, `activeChat`
  - `messages`
  - `draftMessage`, `newPhone`
- **localStorage:** ключи `max-chat:chats` и `max-chat:auth` (опционально).

**Схема интерфейса:**

```
┌────┬───────────────┬────────────────────────┐
│    │  Чаты    [+]  │                        │
│ 💬 ├───────────────┤                        │
│ 📁 │  [поиск]      │      паттерн           │
│ 📂 ├───────────────┤      космос            │
│    │  чат 1        │                        │
│    │  чат 2        │                        │
│    │  чат 3        │                        │
└────┴───────────────┴────────────────────────┘
```

### 2. Авторизация

1. **Создать состояния** в `App.jsx`: `idInstance`, `apiTokenInstance`, `isAuthorized`.
2. **Написать JSX формы:** два `<input>` + `<button>`.
3. **Написать `handleAuthorize`:**
   - Проверить, что оба поля заполнены.
   - Если пусто — показать `alert`.
   - Если ок — установить `isAuthorized = true`.
4. **Условный рендер:** если `!isAuthorized` — показать форму, иначе — основной интерфейс.
5. **localStorage (по желанию):** сохранять данные по ключу `max-chat:auth`. При монтировании читать из localStorage — если данные есть, пропустить экран авторизации.

### 3. Создание чата

1. **Создать состояния:** `chats` (массив), `activeChat` (индекс), `newPhone` (строка ввода).
2. **Написать функцию `phoneToChatId(phone)` в `api.js`:**
   - Убрать все нецифровые символы.
   - Если номер начинается с `8` — заменить на `7`.
   - Добавить `@c.us` в конец.
3. **Написать функцию `handleCreateChat`:**
   - Взять значение `newPhone`.
   - Проверить, что не пусто.
   - Преобразовать в `chatId`.
   - Проверить, нет ли уже такого чата в `chats`.
   - Если есть — сделать его активным.
   - Если нет — добавить новый объект `{ chatId, name }` и сделать активным.
   - Очистить поле ввода.
4. **Отрисовать список чатов** в сайдбаре через `chats.map(...)`.
5. **Обработать клик по чату** — `setActiveChat(index)`.
6. **В окне чата:** если `activeChat === null` — заглушка, иначе — заголовок с именем чата, список сообщений, поле ввода.

### 4. Работа с Green API (бэкенд)

> **Свой бэкенд не пишешь.** Все запросы идут из браузера напрямую к `https://api.green-api.com`.

В `api.js` написать четыре функции:

#### 4.1. `sendTextMessage(idInstance, apiTokenInstance, chatId, message)`

```
POST https://api.green-api.com/waInstance{idInstance}/sendMessage/{apiTokenInstance}
```

- **Тело:** `{ chatId, message }` в JSON.
- **Заголовок:** `Content-Type: application/json`.
- **Возвращает:** `{ idMessage }` при успехе.

#### 4.2. `receiveNotification(idInstance, apiTokenInstance)`

```
GET https://api.green-api.com/waInstance{idInstance}/receiveNotification/{apiTokenInstance}?receiveTimeout=5
```

- **Возвращает:** объект уведомления или `null`, если очередь пуста.

#### 4.3. `deleteNotification(idInstance, apiTokenInstance, receiptId)`

```
DELETE https://api.green-api.com/waInstance{idInstance}/deleteNotification/{apiTokenInstance}/{receiptId}
```

- **Возвращает:** `{ result: true }`.

#### 4.4. `phoneToChatId(phone)`

Преобразование номера в формат `chatId` (см. шаг 3).

### 5. Отправка сообщения

1. **Создать состояние** `draftMessage`.
2. **Поле ввода привязать** к `draftMessage` через `onChange`.
3. **Написать `handleSendMessage`:**
   - Проверить, что текст не пустой и чат выбран.
   - Вызвать `sendTextMessage(...)` с активным `chatId`.
   - При успехе — добавить сообщение в `messages[chatId]` с `fromMe: true`.
   - Очистить `draftMessage`.
   - При ошибке — `console.error` + `alert`.
4. **Обработать Enter** в поле ввода через `onKeyDown`.

---

### 6. Получение сообщений (polling)

1. **Написать `useEffect`,** который запускается при `isAuthorized === true`.
2. **Внутри определить функцию `poll`:**
   - Вызвать `receiveNotification(...)`.
   - Если `null` — выйти.
   - Проверить `notification.body.typeWebhook === "incomingMessageReceived"`.
   - Извлечь `chatId` из `body.senderData.chatId`.
   - Извлечь текст из `body.messageData.textMessageData.textMessage`.
   - Добавить сообщение в `messages[chatId]` с `fromMe: false`.
   - Вызвать `deleteNotification(idInstance, apiTokenInstance, notification.receiptId)`.
3. **Запустить `poll` сразу** и затем через `setInterval(poll, 5000)`.
4. **Сохранить ID интервала в `useRef`**, чтобы очистить при размонтировании.
5. **Вернуть cleanup-функцию** из `useEffect`: `clearInterval(pollingRef.current)`.

---

### 7. Сохранение чатов в localStorage

**При любом изменении `chats` — сохранять:**

```javascript
useEffect(() => {
    localStorage.setItem("max-chat:chats", JSON.stringify(chats));
}, [chats]);
```

**При монтировании — читать из localStorage:**

```javascript
const [chats, setChats] = useState(() => {
    const saved = localStorage.getItem("max-chat:chats");
    return saved ? JSON.parse(saved) : [];
});
```

**Аналогично для:**
- `messages` — чтобы история не пропадала.
- `idInstance` и `apiTokenInstance` — чтобы не вводить каждый раз.
