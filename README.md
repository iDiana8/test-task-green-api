Мне надо сделать приложение на Реакт, которое было бы простеньким ,имело бы интерфес как у MAX. Я это приложение выложу на бесплатный хостинг. 

Пользователь переходит по ссылке на сайт чата, вводит туда свои учетные данные idInstance, apiTokenInstance, потом вводит номер телефона получателя, создается новый чат, который можно переименовать, по умолчанию - номер телефона, я пишу сообщение на этот номер и текстовое сообщение отправляется в МАХ на указанный номер телефона. Получатель отвечает на сообщение и мне в мой чат приходит ответ от др. пользователя.

Я должна реализовать отправку и получение только текстовых сообщений. Для отправки текстового сообщения требуется выполнить запрос по адресу:

отправка: POST
{{apiUrl}}/waInstance{{idInstance}}/sendMessage/{{apiTokenInstance}}

получение: GET
Для получения входящих уведомлений требуется выполнить последовательно вызов двух методов:
Метод ReceiveNotification выполняет получение входящего уведомления.
Метод DeleteNotification подтверждает успешное получение и обработку уведомления.
